# ETF 듀얼 모멘텀 로테이션 백테스트 — 설계 문서

- 작성일: 2026-05-19
- 상태: 승인됨 (구현 계획 수립 대기)
- 프로젝트: `stock-backtest` (독립 Python 프로젝트, EEL 저장소와 무관)

## 1. 목적

한국 상장 미국·테마 ETF 유니버스를 대상으로 **듀얼 모멘텀 로테이션 + 익절** 전략을
과거 시세로 백테스트하여 성과(수익률·MDD·Sharpe 등)를 검증하는 프로그램.

본 단계는 **백테스트/전략 연구**에 한정한다. 실제 주문·실계좌 연동은 범위 밖이며,
여기서 검증된 전략을 추후 모의투자 → 실전으로 승격하는 것을 후속 단계로 둔다.

## 2. 비목표 (이번 범위에서 제외)

- 실계좌·키움 OpenAPI 연동 및 실제 주문 체결
- 모의투자(페이퍼 트레이딩) 실시간 실행
- 분배금(배당) 재투자를 반영한 총수익률(Total Return) — v2 과제
- 분봉/틱 데이터 (일봉만 사용)
- 웹 UI / 대시보드 (CLI + 정적 리포트만)

## 3. ETF 유니버스

초기 종목 (설정 파일로 관리, 확장 가능):

1. TIGER 미국S&P500
2. TIGER 미국테크TOP10 INDXX
3. KODEX 미국AI반도체TOP3플러스
4. TIGER 미국필라델피아AI반도체나스닥
5. TIGER 미국필라델피아반도체나스닥
6. TIGER 글로벌AI&로보틱스 INDXX
7. TIGER 미국배당다우존스
8. KODEX 인도Nifty50

**종목코드 해석**: 코드를 하드코딩하지 않는다. `FinanceDataReader`의
`fdr.StockListing('ETF/KR')` 목록에서 **이름 → 종목코드**를 매핑·검증하고,
확정 매핑을 설정 파일(`config.py` / `data/universe.py`)에 캐싱한다.
이름 변경·중복 시 수동 오버라이드를 허용한다.

**동적 유니버스**: 일부 ETF는 2023~2024년 상장으로 과거 데이터가 짧다.
엔진은 각 ETF의 상장일을 인지하여, 상장 전 구간은 NaN 처리하고
상장 후 + 모멘텀 lookback 충족 시점부터 선택 후보로 편입한다.

## 4. 전략 규칙

모든 수치는 `config.py` 파라미터로 노출하며, 아래는 기본값이다.

### 4.1 상대 모멘텀 (종목 선택)

- 매월 **첫 거래일**에 리밸런싱.
- 각 ETF의 모멘텀 점수 = **최근 12개월 수익률 − 최근 1개월 수익률** ("12-1" 모멘텀).
  - lookback 방식은 파라미터(`momentum_lookback_months`, `momentum_skip_months`)로
    단순 N개월 수익률로도 전환 가능.
- 모멘텀 점수 상위 **K = 3** 종목 선택, 각 **1/K 동일 비중**.
- lookback 데이터가 부족한(상장 직후) ETF는 후보에서 제외.

### 4.2 절대 모멘텀 (하방 방어)

- 기본 활성 (`use_absolute_momentum = True`).
- 선택된 ETF라도 자기 모멘텀 점수가 `absolute_momentum_threshold`(기본 0.0) 미만이면
  해당 슬롯은 매수하지 않고 **현금** 보유.
- 모든 슬롯이 탈락하면 그 달은 100% 현금.

### 4.3 익절 (+5%)

- `use_take_profit` 기본 True, `take_profit_pct` 기본 0.05.
- 매 거래일 **종가** 기준, 보유 종목의 (현재가 / 진입가 − 1) ≥ 5% 이면 익절 신호.
- 체결: 보수적으로 **다음 거래일 시가**에 전량 매도.
- 익절 후 해당 슬롯은 **다음 월간 리밸런싱까지 현금 보유** (월중 재진입 없음 —
  "월 1회 리밸런싱" 원칙 유지).
- 진입가는 매수 체결가(비용 반영 전 체결가) 기준으로 포지션별 추적.

> **트레이드오프 (명시)**: +5% 익절은 강세 추세에서 상승분을 조기에 잘라
> 모멘텀 전략의 수익을 깎을 수 있다. 따라서 익절은 토글·익절률 파라미터로
> 분리하여, 익절 ON/OFF 두 시나리오를 동일 조건에서 비교 리포트한다.

### 4.4 거래비용

- 매수·매도 각각 체결금액 대비 비율 비용 적용.
- 기본: 수수료 0.015% + 슬리피지 0.035% = **편도 0.05%** (왕복 약 0.1%).
- `commission_rate`, `slippage_rate` 파라미터로 조정.
- 세금(증권거래세 등)은 ETF 특성상 단순화하여 슬리피지에 포함(주석으로 명시).

## 5. 백테스트 사양

- 기간: 기본 **2016-01-01 ~ 실행일** (`start_date`, `end_date` 파라미터).
- 데이터: `FinanceDataReader` 일봉 OHLCV, 로컬 캐시(`data/cache/*.csv`).
- 가격 기준: **수정종가 아닌 가격수익률**(분배금 미반영) — 한계로 명시, v2 보정 과제.
- 초기 자본: 기본 10,000,000원 (`initial_capital`).
- 벤치마크: **TIGER 미국S&P500 매수후보유**를 비교 기준으로 함께 산출.
- 리밸런싱 체결: 신호 산출일의 **다음 거래일 시가** (look-ahead bias 방지).

## 6. 아키텍처

```
stock-backtest/
  config.py              # 유니버스, 전략·비용·기간 파라미터 (단일 진실 공급원)
  data/
    loader.py            # FinanceDataReader 일봉 로드 + CSV 캐시
    universe.py          # 이름→종목코드 매핑/검증, 상장일·동적 유니버스 처리
  strategy/
    momentum.py          # 모멘텀 점수·랭킹·절대모멘텀 필터·익절 신호 생성
  engine/
    backtest.py          # 일봉 루프: 월 리밸런싱 + 일중 익절, 포지션/현금/거래기록
    portfolio.py         # 포지션·현금·진입가·평가금액 상태 관리
    costs.py             # 수수료·슬리피지 비용 모델
  metrics/
    performance.py       # CAGR·총수익·MDD·Sharpe·Sortino·변동성·승률·회전율·연도별
  report/
    report.py            # 자산곡선·드로다운 차트(PNG), 거래로그 CSV, 요약 HTML/콘솔표
  run_backtest.py        # CLI 진입점 (argparse로 config 오버라이드)
  tests/                 # pytest
  docs/specs/            # 본 설계 문서
  requirements.txt
  README.md
```

### 6.1 데이터 흐름

`loader`(시세 캐시 적재)
→ `universe`(코드 매핑·상장일·유효 후보 산출)
→ `strategy.momentum`(월별 신호: 선택 종목·목표 비중·익절 신호)
→ `engine.backtest`(일봉 루프에서 체결·익절·비용 시뮬, `portfolio` 상태 갱신)
→ `metrics.performance`(성과 지표 계산)
→ `report`(차트·표·로그 출력).

### 6.2 모듈 책임 (경계)

- `data.loader`: ETF 코드 → 일봉 DataFrame 반환·캐싱. 전략·엔진을 모름.
- `data.universe`: 이름↔코드, 상장일, 특정일 기준 거래가능 종목 집합 제공.
- `strategy.momentum`: 가격 데이터 입력 → 일자별/월별 신호 출력. 체결·비용을 모름 (순수 함수).
- `engine.portfolio`: 보유수량·현금·진입가 상태와 평가금액. 신호를 모름.
- `engine.backtest`: 신호+포트폴리오를 받아 일봉 루프로 시뮬. look-ahead 방지 규칙의 단일 소유자.
- `metrics.performance`: 자산곡선·거래로그 입력 → 지표 출력. 순수.
- `report.report`: 지표·곡선 입력 → 파일/콘솔 출력. 계산 없음.

### 6.3 핵심 엣지 케이스 (엔진이 명시적으로 처리)

- 리밸런싱일: 상위 K 이탈 종목 매도 → 신규 편입 매수 → K종목 동일 비중 재구성.
- 절대 모멘텀 전부 탈락 → 그 달 100% 현금.
- 월중 익절로 비워진 슬롯 → 다음 리밸런싱까지 현금(즉시 재진입 안 함).
- 상장 전 ETF → 랭킹에서 제외 (NaN).
- lookback 미충족(상장 직후) ETF → 후보 제외.
- 데이터 결측/거래정지일 → 직전 유효가 forward-fill, 신호일은 결측 시 제외.
- 신호일=마지막 거래일이라 "다음 거래일"이 없으면 해당 리밸런싱 스킵.

## 7. 산출물 (리포트)

- 콘솔 요약표: 총수익률, CAGR, MDD, Sharpe, Sortino, 변동성, 승률, 회전율, 거래횟수.
- 연도별 수익률 표.
- 자산곡선 + 드로다운 차트 PNG (전략 vs 벤치마크).
- 거래 로그 CSV (일자, 종목, 매수/매도, 수량, 체결가, 비용, 사유[리밸런싱/익절/절대모멘텀]).
- 요약 HTML 1장 (표 + 차트 임베드).
- 익절 ON/OFF 비교 모드: 동일 기간 두 시나리오 지표를 나란히 출력.

## 8. 기술 스택

- Python 3.11+
- 의존성: `finance-datareader`, `pandas`, `numpy`, `matplotlib`, `pytest`
- 패키지 매니저: pip + `requirements.txt` (venv 권장)

## 9. 테스트 전략 (pytest)

- `strategy.momentum`: 합성 가격으로 12-1 점수·랭킹·절대모멘텀 필터 검증.
- 익절 로직: 진입가 대비 +5% 도달 시 다음날 시가 청산 신호 발생 검증.
- `engine.costs`: 매수/매도 비용 계산 정확성.
- `engine.backtest`: 결정적 합성 데이터로 통합 시나리오 (리밸런싱·익절·현금 전환).
- look-ahead 방지: 신호일 데이터로 같은 날 체결이 일어나지 않음을 단언.
- `metrics.performance`: 알려진 자산곡선에 대한 CAGR/MDD 수치 검증.

## 10. 알려진 한계 (의도된 단순화)

- 분배금 미반영(가격수익률) → 배당형 ETF 성과 과소평가. v2: 총수익률 보정.
- 신규 상장 ETF 과거 데이터 짧음 → 전체 유니버스 구간 별도 리포트로 보완.
- 세금 단순화(슬리피지에 포함).
- 단일 통화(KRW), 환헤지/환노출 구분 안 함 (한국 상장분 KRW 기준 그대로).
